# Exercises

Module exercises apply the lesson with normal, edge, and failure or adversarial cases.

## How to use

1. Open the matching module from [Start Learning](../learn/index.md).
2. Attempt the exercise before the quiz or explained solution.
3. Satisfy the written pass conditions before marking the module complete.

Authoritative exercise packets live in the repository under labs/exercises/ and are also linked
from each curriculum module directory. This page is the documentation-site hub so visitors land on
a real practice entry instead of an empty overview.
