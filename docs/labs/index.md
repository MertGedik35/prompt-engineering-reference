# Practice & Labs

Hands-on work that turns lessons into evidence. Use labs after reading a module lesson — or jump
here when you already know the concept and need practice.

## Recommended order

```text
Lesson → Exercise → Quiz → Explained solution → Checklist → Capstone
```

1. Read the module lesson from [Start Learning](../learn/index.md).
2. Attempt the [exercise](exercises.md) with its normal, edge, and failure cases.
3. Take the [quiz](quizzes.md) without the answer key open.
4. Review the [explained solution](solutions.md) only after your attempt.
5. Complete the module checklist.
6. When ready, ship a [capstone](capstones.md).
