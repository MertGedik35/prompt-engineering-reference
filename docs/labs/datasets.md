# Datasets

Shared inputs used by evaluation fixtures and selected practice tasks.

## How to use

1. Prefer the dataset named by an [evaluation fixture](evaluations.md) or module exercise.
2. Keep original provenance notes when you adapt a sample for your own test suite.
3. Do not invent issuer claims or personal data while expanding a dataset.

Authoritative dataset files live in the repository under `labs/datasets/`.
