# Evaluation fixtures

Reusable evaluation packs for comparing prompts, checking assertions, and practicing release-gate
thinking from the Evaluation module.

## How to use

1. Read [Evaluation](../learn/evaluation.md) for the curriculum framing.
2. Open fixtures under the repository path `labs/evaluations/`.
3. Pair fixtures with [datasets](datasets.md) when a case needs shared inputs.

This hub keeps evaluation practice discoverable from the documentation site without duplicating
fixture files into `docs/`.
