# Quizzes

Each module quiz has eight questions that check discrimination, not trivia recall alone.

## How to use

1. Finish the lesson and exercise attempt first.
2. Take the quiz without opening the answer key.
3. Treat at least 6 of 8 correct answers as the completion bar used by the learning path.

Authoritative quiz files live in the repository under `labs/quizzes/` and inside each curriculum
module folder. Use [explained solutions](solutions.md) only after your attempt.
