# Learn

The curriculum teaches foundations first, then prompt anatomy, techniques, grounding, structured outputs, evaluations, agents, context engineering, security, multimodal prompting, production operations, and capstone work.

The authoritative lessons live under
[`curriculum/`](https://github.com/MertGedik35/prompt-engineering-reference/tree/feat/v2-learning-reference/curriculum).
The pages in this section are intentionally short site-navigation entries so a second lesson copy
cannot drift. Each entry links the lesson, exercise, quiz, solution, references, and checklist.
