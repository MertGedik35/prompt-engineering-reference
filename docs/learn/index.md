# Start Learning

This hub is the documentation-site entry into the 13-module curriculum. Authoritative lesson text
lives under `curriculum/`; each module page below is a short navigation entry that links the
lesson, exercise, quiz, solution, references, and checklist without maintaining a second lesson
copy.

## How to practice

```text
Lesson → Exercise → Quiz → Explained solution → Checklist → Capstone
```

Attempt the exercise and quiz before opening the explained solution. Completion expects the
exercise pass conditions, at least 6 of 8 quiz questions, and an honest checklist review.

## Paths

| Visitor | Suggested start |
| --- | --- |
| New to prompt engineering | Phase 1 from Orientation |
| Returning practitioner | Jump to the phase that matches your gap, or open [Prompt Reference](../reference/index.md) |
| Building a portfolio | Finish Phase 4, then open [Capstones](../labs/capstones.md) |
