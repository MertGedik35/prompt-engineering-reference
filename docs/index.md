# Prompt Engineering Reference

Learn prompt engineering in a fixed order, then return for daily lookup of patterns, templates,
provider notes, and verified resources.

**V1 is published. V2 remains a draft under review — not a released `v2.0.0`.**

## What is inside

- **13** curriculum modules with lessons, exercises, quizzes, and explained solutions
- **26** prompt patterns and **28** reusable templates
- **8** provider guides with dated fast-stale claims

- Cataloged official resources, courses, credentials, papers, books, videos, tools, communities,
  and reference repositories
