# Version 2 Release Notes

These notes describe Version 2 repository contents. They do not assert that a GitHub `v2.0.0` tag
or GitHub Release already exists.

## Highlights

- Learning and Reference modes with separate source areas and a visitor-first documentation site.
- A 13-module curriculum with lessons, exercises, quizzes, explained solutions, references, and
  completion checklists.
- Twenty-six prompt patterns and twenty-eight reusable templates with semantic quality gates and
  generated human-readable indexes.
- Eight dated provider guides with official versus supporting source classification and nested
  freshness inheritance.
- Typed resource catalogs for official documentation, structured learning resources, credentials,
  papers, books, videos, tools, communities, and repositories.
- Three capstone projects plus practice hubs for exercises, quizzes, solutions, evaluations, and
  datasets.
- Schema, catalog, privacy, freshness, internal-link, external-link, README navigation, and
  publication-readiness validation.

## Structured learning and credentials

Version 2 distinguishes structured courses, learning modules, learning paths, interactive
tutorials, guided labs, and exercise repositories. Credential records separate individual
credentials from credential-family overview records, and verification evidence is typed by issuer
mechanism.

Current inventory:

- 8 structured learning resources
- 4 individual credentials and 1 credential-family overview
- 24 official-resource catalog records

## Pages deployment

Documentation is built with MkDocs and deployed from `main` through the repository Pages workflow.
Edit links are configured for `main` documentation sources.

## Migration notes

V1 flat documentation routes were replaced by Learning, Prompt Reference, Provider, Resource, and
Practice hubs. Known V1 path replacements are listed in
[V1 to V2 Migration](v1-to-v2-migration.md). HTML redirects for renamed V1 routes remain optional
backlog.

## Known non-blocking limitations

- Broader official-resource, course, and credential expansion remains backlog.
- Live cross-provider API benchmarks are out of scope.
- Advanced SEO polish and repository-description updates remain optional.
