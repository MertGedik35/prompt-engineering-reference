# Courses & Resources

Curated external material for learning and daily lookup. Every catalog page records official vs
community classification where applicable, free/paid or credential status where applicable, and a
verification date. Treat dated claims as freshness-sensitive.

## How to read status fields

- **Official vs supporting/community** tells you ownership, not quality alone.
- **Free / paid / freemium / subscription** describes access, not credential value.
- **Credential status** is separate from course completion; a completion certificate is not a
  formal certification unless the issuer says so.
- **Verification date** and freshness risk tell you when to re-check the canonical page.

Orientation lessons explain the cost and credential taxonomies used in this repository.
