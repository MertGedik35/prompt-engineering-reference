# Official prompts

Issuer-owned prompt galleries and example collections are tracked separately from community
write-ups.

## How to use

1. Prefer [official resources](../generated/official-resource-index.md) when you need the canonical
   documentation page.
2. Open the repository folder `resources/official-prompts/` for curated prompt-collection indexes.
3. Re-check verification dates before copying examples into production.
