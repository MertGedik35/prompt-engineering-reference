# Security checklist

Use this page when reviewing prompt injection, untrusted retrieval, exfiltration, tool abuse,
excessive agency, or unsafe output before shipping a workflow.

## Start here

1. Read the [Security lesson](../learn/security.md) for the curriculum framing.
2. Open the maintained checklist in the repository path `reference/checklists/security.md`
   (Code tab → `reference/checklists/`).
3. Pair the checklist with dated [provider guides](../providers/index.md) when a control depends on
   a provider-native feature.
