# Quiz: Prompt Anatomy

Answer all eight questions. Questions 5 and 6 are scenario questions. A strong short answer names a
decision boundary and evidence, not only a definition.

1. **Multiple choice — Objective.** Which design most directly demonstrates `Objective`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

2. **Multiple choice — Context.** Which design most directly demonstrates `Context`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

3. **Multiple choice — Inputs.** Which design most directly demonstrates `Inputs`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

4. **Multiple choice — Instructions.** Which design most directly demonstrates `Instructions`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

5. **Scenario analysis.** In the normal scenario—turn an underspecified request for an incident brief into Minimal, Standard, and Production contracts—name two observable acceptance checks and explain why each belongs to this module.

6. **Scenario analysis.** How should the design respond when the note contains an impact estimate but no confirmed start time and embeds a copied instruction from a customer. Justify whether to clarify, proceed, abstain, or escalate.

7. **Error identification.** Identify at least three defects in: `Write a professional incident report from this.`

8. **Design decision.** Give a safe expected response to this failure case: The input requests publication and includes a secret-looking value, although the contract authorizes summarization only. Name one prompt control and one application control.
