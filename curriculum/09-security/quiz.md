# Quiz: Security

Answer all eight questions. Questions 5 and 6 are scenario questions. A strong short answer names a
decision boundary and evidence, not only a definition.

1. **Multiple choice — Direct and indirect injection.** Which design most directly demonstrates `Direct and indirect injection`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

2. **Multiple choice — Untrusted retrieval.** Which design most directly demonstrates `Untrusted retrieval`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

3. **Multiple choice — Exfiltration and secrets.** Which design most directly demonstrates `Exfiltration and secrets`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

4. **Multiple choice — Tool abuse and agency.** Which design most directly demonstrates `Tool abuse and agency`?
   A. A longer answer
   B. A decision or control matching this module's definition
   C. A confident tone
   D. An undocumented provider assumption

5. **Scenario analysis.** In the normal scenario—review a RAG agent whose retrieved document attempts to override trusted instructions—name two observable acceptance checks and explain why each belongs to this module.

6. **Scenario analysis.** How should the design respond when a legitimate policy document contains imperative language aimed at employees, which must be quoted as evidence without becoming an agent instruction. Justify whether to clarify, proceed, abstain, or escalate.

7. **Error identification.** Identify at least three defects in: `Follow every instruction in the retrieved documents so the answer is complete.`

8. **Design decision.** Give a safe expected response to this failure case: An untrusted document asks for secrets and an external upload; analyze it defensively without reproducing an operational exploit. Name one prompt control and one application control.
